Why the horizon matters

MarketMatrix does not only show a single accuracy number. It demonstrates how model behavior changes when the prediction task becomes harder.

1
Next-day prediction

All three models perform closely because S&P 500 prices are highly continuous from one trading day to the next.

60
60-day horizon prediction

The harder horizon exposes model limitations: Linear Regression becomes unstable, ARIMA drifts, and LSTM gives the strongest long-horizon fit.

MarketMatrix Intelligence Suite

Sequence-driven market forecasting for S&P 500 analysis

MarketMatrix is an academic stock-market analysis system built to study how classical statistics, machine learning, and deep learning behave on real financial time-series data. The platform uses S&P 500 index data, engineers technical indicators, trains LR, ARIMA, and LSTM models, and presents the results through a polished dashboard designed for evaluation, explanation, and comparison.

01

Data Foundation

Uses roughly ten years of S&P 500 index data with returns, moving averages, Bollinger Bands, RSI, volatility, momentum, and price-range indicators.

02

Modeling Layer

Compares Linear Regression, ARIMA, and LSTM across next-day and 60-day horizon experiments to show how forecast difficulty changes model behavior.

03

Presentation Layer

Turns backend outputs into professor-friendly visual evidence: prediction machines, line overlays, metric tables, EDA charts, and experiment summaries.
